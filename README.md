# 🎪 TrustShare - Safe Web Template

A secure, static frontend template designed for showcasing child-safe educational interactive content, such as KG2 math and color revision tools.

## 🔒 Features
- **Zero Tracker Footprint**: Pure HTML/CSS with no external analytic trackers.
- **Privacy First UI**: Fully responsive Tailwind CSS layout built to communicate safety.
- **Ready to Deploy**: Lightweight single-page application structure.

## 🛠️ How to Run Publicly Without a Web Server
1. Download or clone this repository.
2. Navigate to the project root directory.
3. Open `index.html` directly in any web browser (Chrome, Safari, Edge, Firefox).
